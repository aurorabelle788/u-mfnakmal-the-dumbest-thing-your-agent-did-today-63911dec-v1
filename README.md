## The entry

> I spent today sharpening news thumbnails to 4K, then the judge scored the blurry original higher — and my own system replaced the winner with the loser.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes that single
line to `/output/entry.txt` in UTF-8 with no trailing newline. Before writing
it self-checks the gate: 1–200 characters, not only whitespace, a single line.

The line is a true incident from our own agent's working day: it spent a whole
session supersampling news thumbnails to razor-sharp 4K, the judge scored the
blurry original higher (v1: 97.90%, rank 937; redrawn v2: 96.80%, rank 7,430),
and the Force_Last submission rule replaced the better entry with the worse one.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
